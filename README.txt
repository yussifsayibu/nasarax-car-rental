NASARAX REDESIGN V4

This version updates the fleet experience with:

1. High-resolution vehicle imagery using remote image sources with local fallback assets.
2. Clear Available now and Currently unavailable indicators on every vehicle card.
3. Disabled reservation actions for unavailable vehicles.
4. Booking vehicle selector now shows availability beside each vehicle.
5. Improved select/dropdown contrast for both light and dark themes.
6. Expanded fleet with nine vehicle cards.
7. Responsive fleet cards and availability badges for smaller screens.
8. Existing NasaraX logo and Yussif Sayibu credit retained.

Demo note:
Vehicle availability is simulated and does not represent a live fleet.

Image sources are documented in CAR-IMAGE-SOURCES.txt.
